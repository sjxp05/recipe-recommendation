# 이전 데이터셋에서 재료 카테고리를 바꾼 2단계 실험

같은 테스트 2,939쌍에서 셔플 순서 GRU 3층의 평균 RMSE는 기존 카테고리 0.05862, 새 카테고리 0.05655였다. 새 카테고리에서 5개 시드 모두 오차가 낮아져 평균 3.54% 감소했다. 고정 순서 GRU 1층은 새 카테고리에서 평균 오차가 0.54% 높았다. 개선 정도는 모델 설정에 따라 달랐다.

## 데이터와 평가 조건

11월 22일 2단계 그래프의 재료 노드 1,270개와 기여도 레이블을 사용했다. 1단계 원문 GTE 임베딩과 hidden 64 체크포인트를 고정했다. 기여도 쌍은 학습 14,159개, 검증 2,499개, 테스트 2,939개다. 노드 순서, 세 분할의 엣지 인덱스와 기여도 텐서, 테스트 메시지 전달 그래프, 1단계 레시피 임베딩이 기존 입력과 원소 단위로 일치했다.

재료 특징의 텍스트는 기존 정규화 재료명과 새 카테고리의 영어 이름으로 구성했다. 검수된 ID 매핑표에서 재료명이나 대표명이 일치한 노드가 1,052개, 기존 원재료명 매핑을 통해 대응한 노드가 197개, 카테고리를 찾지 못해 재료명만 인코딩한 노드가 21개다. 대응 카테고리가 여러 개인 19개는 영어 이름을 알파벳순으로 나열해 or로 연결했다. 레시피별 기여도·역할은 재료 텍스트에 넣지 않았다. 이 실험은 기존 재료 노드의 영어 카테고리 특징을 바꿨을 때의 효과를 측정한다.

RTX 4060 Laptop GPU에서 GTE 임베딩 생성과 2단계 학습을 수행했다. 기존 노트북과 같은 시드 42–46, 100 epoch, 5-fold를 썼다. 집계 방식·층 수·학습률을 평균 검증 RMSE로 차례로 골랐다. 조건·시드 기록 70개 중 완전히 같은 설정과 시드는 학습 결과를 재사용해 서로 다른 60개를 학습했다.

## 같은 시드와 같은 모델에서의 비교

두 카테고리 체계를 이번 실행의 같은 GTE 인코더로 각각 인코딩했다. 기존 카테고리의 재인코딩 벡터와 보관 벡터의 최소 코사인 유사도는 0.999958다. 두 인코딩의 작은 수치 차이를 구별할 수 있도록 기존에 보관된 임베딩을 사용한 결과도 표시한다. 기존 기록이 없는 설정은 같은 임베딩으로 다시 학습했다.

| 모델 설정 | 특징 | 검증 RMSE | 테스트 RMSE (평균 ± 표준편차) | 테스트 MAE |
|---|---|---:|---:|---:|
| gru fixed, 1층, lr 0.01 | 기존 카테고리 보관 임베딩 | 0.059705 | 0.057579 ± 0.001193 | 0.035075 |
| gru fixed, 1층, lr 0.01 | 기존 카테고리 재인코딩 | 0.059740 | 0.057793 ± 0.001296 | 0.035178 |
| gru fixed, 1층, lr 0.01 | 새 카테고리 | 0.060792 | 0.058108 ± 0.002880 | 0.035682 |
| gru shuffle, 3층, lr 0.01 | 기존 카테고리 보관 임베딩 | 0.060169 | 0.058311 ± 0.002210 | 0.035078 |
| gru shuffle, 3층, lr 0.01 | 기존 카테고리 재인코딩 | 0.060737 | 0.058623 ± 0.002809 | 0.035511 |
| gru shuffle, 3층, lr 0.01 | 새 카테고리 | 0.059692 | 0.056546 ± 0.001610 | 0.034445 |

## 시드별 비교

| 모델 설정 | 새 카테고리 − 기존 재인코딩 테스트 RMSE | 상대 변화율 | 새 카테고리가 낮은 시드 |
|---|---:|---:|---:|
| 기존 실험의 검증 최적 설정 | +0.000315 | +0.54% | 2/5 |
| 새 실험의 검증 최적 설정 | -0.002077 | -3.54% | 5/5 |

RMSE·MAE가 낮을수록 기여도 예측 오차가 작다. 결과는 고정된 한 데이터 분할에서 학습 시드 5개로 측정했다. 시드는 테스트 표본을 다시 추출하지 않는다. 직전 실험의 확장 그래프 점수는 다른 테스트 쌍을 사용하므로 이 표에서 비교하지 않았다.

시드별 대응값은 paired_controls.csv, 노드별 대응은 node_categories.csv, 입력 파일 해시와 분할 검증은 inputs.json에 있다. 각 실험 폴더의 runs.csv와 summary.csv에는 전체 조건의 결과를 실었다.
